# AulaConectada
Aula Conectada es un prototipo escolar que utiliza una ESP32-S3, una pantalla LCD, WiFi y una página web para organizar y visualizar información de asistencia. Busca demostrar cómo un circuito físico puede comunicarse con un sistema digital para reemplazar registros manuales por datos más rápidos, claros y fáciles de consultar.
